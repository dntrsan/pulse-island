# Pulse Island

コーディング AI（Claude Code・Codex・Antigravity）の様子を、iPhone の Dynamic Island とウィジェットで見るアプリ。
データは PC で動いている [Claude Pulse](../claude-pulse) の `/api/island` から取る。

## 見え方

- **Dynamic Island の左**：AI ごとのキャラが、いまの作業に合わせて動く
  - Claude：Claude Code のドット絵の子。考え中は上下に揺れて「…」、読むときは目を左右に、書くときは腕を交互に、コマンドは足踏み
  - Codex：端末の四角に記号、Antigravity：惑星のまわりを点が回る
- **右**：作業中はこのターンの経過時間、返事待ちは「返答」、終わったら ✓
- **長押し・ロック画面**：タイトル、いまやっていること（または質問の中身）、タスクの進み、5 時間枠と週枠
- **返事を求められたら**：アイランドが大きく開いて音が鳴る。選んでいないセッションでも、返事待ちになったものを優先して出す
- **ウィジェット**：3 つの AI のリミット。中サイズには、アイランドを出し直すボタンがある

## 仕組み

無料の Apple ID ではプッシュ通知が使えないので、アプリは無音の音声を流して裏で動き続け、
Pulse に `?wait=<版>` を付けて聞きに行く（変化があるまで最長 25 秒待ってから返ってくる）。
変化があればアプリがライブアクティビティを書き換える。

**書き換えの制限**：iOS 18 からは、ライブアクティビティの書き換えに間隔と回数の制限がある。
最初の版は 2 秒ごとに書き換えてキャラを動かしていたが、しばらくすると止められた（2026-11-02）。そこで次のようにした。

- **キャラのコマは書き換えずに進める**：経過時間の表示（`Text(timerInterval:)`）だけは iOS 自身が毎秒書き換えるので、
  数字の 0〜9 の形をコマにしたフォント（`Shared/Fonts/PulseFrames-*.ttf`）で表示する。秒の 1 の位が進むたびにコマが進む。
  前の桁とコロンはフォントの中（`calt`）で幅 0 の空白に置き換え、さらに右端の 1 コマだけを切り抜いて見せる。
  色はフォントに持たせられないので、体と飾り（「…」「!」など）を別のフォントにして重ねる。
  時計の表示に `fixedSize()` を付けると、ライブアクティビティでは幅が NaN になってキャラが消える（実機で踏んだ。[expo/expo#52176](https://github.com/expo/expo/pull/52176)）
- **中身の書き換えは間をあける**：返事待ち・完了・切断はすぐ、ほかは前の書き換えから 15 秒、文言とリミットだけの変化は 60 秒あけてまとめる
- **記録**：設定画面の「記録」に、裏で眠らされていた時間、音声の停止と再開、アイランドの終了、書き換えの回数を残す

フォントは `tools/make_frame_fonts.py` で作る（コマの絵は `Shared/Character.swift` のポーズと同じ決まりで描く。ポーズを変えたら両方直す）。

```powershell
python -E tools\make_frame_fonts.py --check   # フォントと Info.plist の UIAppFonts を作り直し、HarfBuzz で確かめて dist\frames-preview.png に見本を出す
```

- ライブアクティビティは 8 時間で終わる。そのあとはアプリを開くか、ウィジェットの「アイランド」で出し直す
- アプリを上にスワイプして消すと止まる
- ウィジェットはアプリとデータを共有できない（App Groups が使えない）ので、自分で Pulse に聞きに行く。
  最初の 1 回だけ「ウィジェットを編集」で URL と 6 桁のコードを入れる

## リミットの出どころ

| AI | 出どころ |
|---|---|
| Claude | デスクトップアプリが記録する使用率（3 時間以内のものだけ）。古いときは「直近のトークン ÷ これまでの最大」を **目安** として出す |
| Codex | `~/.codex/sessions` のログに残る `rate_limits`（5 時間枠と週枠） |
| Antigravity | 出さない（認証用のトークンが要る API にしかない） |

## ビルドと入れ方

`main` に push すると GitHub Actions（macOS 26 / Xcode 26.6）が署名なしの `PulseIsland.ipa` を作る。

```powershell
.\scripts\fetch-ipa.ps1   # 最新の ipa を dist\ に落とす
```

Sideloadly で無料の Apple ID で署名して入れる。7 日で起動しなくなるので、そのときは入れ直す。
